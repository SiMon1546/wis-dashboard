06 / TECHNICAL DETAILS
รายละเอียดทางเทคนิคและข้อจำกัด

ความสดคำนวณจากอายุข้อมูล: ≤75 นาที LIVE · >75–120 นาที DELAYED · >120 นาที STALE แยกจาก QC ของ Backend การรีเฟรชหน้าไม่ได้ทำให้เวลาตรวจวัดใหม่ขึ้น

“ไม่มีข้อมูล” คือ NULL หรือข้อมูลที่ใช้งานไม่ได้ ไม่ใช่ศูนย์ ความเชื่อมั่นเป็นคะแนนจาก WIS ไม่ใช่ความน่าจะเป็นของน้ำท่วม

ระดับน้ำใช้หน่วยและฐานอ้างอิงจากแหล่งข้อมูลแต่ละสถานี ไม่ควรเปรียบเทียบระดับน้ำข้ามสถานีหรือข้าม datum โดยตรง ระยะถึงตลิ่งเป็นค่าบวกเมื่อน้ำต่ำกว่าตลิ่ง

กราฟใช้เกณฑ์ QC และช่วงค่าของ V1 เดิม: LIVE / DELAYED / STALE / PASS / VALID และ −20 ถึง 100 ม. เส้นเชื่อมเฉพาะจุดห่างไม่เกิน 90 นาทีที่มี datum เดียวกัน ไม่เติมช่องว่าง

V2 ใช้เฉพาะ API แบบอ่านอย่างเดียวที่เผยแพร่อยู่ แหล่งเขื่อน น้ำทะเล และ RID C.29B ยังไม่มีค่าที่เปิดให้ Dashboard นี้
